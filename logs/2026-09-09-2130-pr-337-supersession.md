# PR #337 取代紀錄與 Article／read seam 交付歸屬

## 交付

- 將 WI-035、WI-041、WI-044、WI-049 標記為 `done` 並歸入 WG-024，各自 `Notes` 指向 `site-reset` 上真正的實作與測試入口。
- 確認 WI-056 尚未完成：`apps/cms/workspace.tsx` 缺少 #315 acceptance 要求的 `/cms/entries` 明確 history route，維持 `pending`，不以既有 workspace 功能代替四條 canonical route gate。
- 記錄 PR #337（`feat/article-workspace-runtime`）已被 `site-reset` 的既有 seam 取代並關閉，不合併其程式碼。

## 關鍵決策

`feat/article-workspace-runtime` 與 `site-reset` 平行實作了多個既有 seam，對 base 有大量無法機械解決的衝突
（含 `apps/authoring-api/cms/` 已被 base 改名為 `apps/cms/` 的 modify/delete 衝突）。逐檔比對後確認 #337 沒有
`site-reset` 缺少、且可安全合併的 seam；但此結論不等於 #315 Article workspace 已完成。

| PR #337 | `site-reset` 現況 |
| --- | --- |
| `core/application/authoring-read-facade.ts` | `core/application/authoring-read.ts`：另含 entry status、title、route graphs、asset availability 與 canonical state digest 穩定性檢查，以及 `ContentTypeAdministration` |
| `/v1/content-types`(GET/POST)、`/v1/entries`、`/v1/entries/:id`、`/v1/entries/:id/revisions`、`/v1/preview` | 五條全部已存在，另有 `/v1/plugins*`、`/v1/entries/:id/current/editor-blocks`、`/v1/entries/:id/seo-analysis` |
| `apps/authoring-api/cms/main.tsx` Article 工作台 | `apps/cms/workspace.tsx` 已有 save、current／published preview、dirty publish lock 與 `<dialog>` 二段 Publish，另有 router、外掛管理、SEO 預覽與 plugin editor block；但缺少 `/cms/entries` 明確 history route |
| `originOk` 允許 `/v1/*` 省略 `Origin` | 已有同修正且更嚴：只有 GET／HEAD 可省略，POST 省略一律拒絕 |
| persistence 列舉 entry pointer／revision／schema version | 已存在於 store 層 |
| 無正式 listener composition root | `apps/authoring-api/cms-serve-cli.ts`、`serve.ts`、`cms-runtime.ts` 已提供 |

因此保留 `site-reset` 的既有實作、關閉 #337，只保留本紀錄。此決策不結案 WI-056；#337 分支與其 review commit 保留在 remote 供追溯，不再更新。
