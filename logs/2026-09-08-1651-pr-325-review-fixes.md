## 交付

- Article editor 的 SaveRevision 失敗不再被回報成「已儲存」：寫入與其後的重新載入分開處理，寫入失敗顯示 listener 的 remediation，只有重新載入失敗才顯示「已儲存，但重新載入失敗」。
- Editor／文章清單／內容類型清單與詳細頁的載入加上 generation 守衛，unmount 或再次載入後過期回應不得覆寫畫面狀態。
- 未發布文章的 preview 404 維持「尚未發布」，不再以空 `srcDoc` 的 iframe 冒充已發布內容。
- Ajv adapter 在 digest cache 命中時不再重新 decode／parse schema bytes；`Intl.Collator` 提到 module scope，不再於每次 sort 比較時重建。
- 移除 `routeFor()` 已不可能回傳的 `"save"` RouteClass、`cmsServeMain()` 兩個分支相同的 ternary，以及 transport 送不出去的 `ArticleSaveInput.expectedCurrentRevisionId`；per-request 的 route class 陣列改為 module-level `ReadonlySet`。
- 新增 Content Type read 與 Ajv adapter 的回歸測試。

## 關鍵決策

- Ajv cache 命中時略過 schema parse 不影響任何驗證性質：原本 parse 出來的 schema 在 cache 命中路徑上會被丟棄，未與 digest 或既有 validator 比對，因此只是重複成本。
- `AUTHENTICATED_ROUTES`／`READ_ROUTES`／`POST_READ_ROUTES` 以 `ReadonlySet` 表示，method 與 origin gate 的成員資格由單一來源決定，避免兩處字串陣列各自漂移。
- 文章清單「草稿」篩選維持既有語意（只含 `draft`，不含 `published-with-draft`），僅改寫成可讀的等價條件。
