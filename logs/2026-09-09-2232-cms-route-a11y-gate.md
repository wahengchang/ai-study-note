# CMS canonical route accessibility gate

## 交付

完成 GitHub #315 四條 canonical CMS routes 的 a11y 補正。`/cms` 只顯示未完成的 draft／published-with-draft 待處理文章與明確 actions；`/cms/entries` 保持完整 catalog。新增與編輯 workspace 保留既有 owner seam，沒有加入 `/cms/preview`、假導航、build、delivery 或 deploy。

每條 CMS history route 使用可聚焦 `#page-title`、具名 main 與 loading live status。文章 workspace 的 current revision、Save／Publish 與 live status 集中於 desktop action sidebar，窄螢幕維持同一閱讀順序。Publish dialog 顯示將發布的 revision，失敗訊息留在 dialog；Current／Published tabs 支援循環鍵盤操作、非顏色 selected cue 與 titled sandboxed iframe。

## 關鍵決策

保留 `/cms/plugins`。它是既有已交付的 Plugin management route，且 `contracts/README.md` 明確要求 document admission；#315 排除的是尚未交付的 Plugin editor workspace。Catalog DTO 沒有時間欄位，因此首頁依可處理狀態篩選，而不虛構近期排序。

## 實際驗證

- `npm run check`：typecheck、architecture check、CMS production build 與 251 tests 全數通過。
- authenticated Chromium browser journey：`/cms` → `/cms/entries` → `/cms/entries/new` → `/cms/entries/:entryId` 的 pathname、skip link 主 heading focus、具名 main、Current／Published keyboard tabs、sandboxed iframe、Publish Escape focus return／revision 說明／成功 status focus、375px 無水平 overflow，以及 published-with-draft。
