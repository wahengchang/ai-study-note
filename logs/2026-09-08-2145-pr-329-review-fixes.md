# PR #329 複審與收斂

- `scripts/check-architecture.ts` 納入 `.tsx`：`defaultIncludes`／`readDirectory` 加入 `.tsx`，program 以 `jsx: ReactJSX` 建立，naming、unit entrypoint、production source 與 import-edge 掃描一併改用 `isTypeScriptSource`。

## 關鍵決策

- contract §6 已核准「checker scan `**/*.{ts,tsx}`」與「TSX architecture」可觀察驗收，但程式未實作；因此本次是補實作，不動 `contracts/README.md`。
- `.tsx` 的 bundler asset import 選擇「以實際檔案走同一組 edge 規則」而非略過，才能同時滿足 base branch 既有的 `apps/authoring-api/cms/main.tsx` 與 contract 的 import 邊界要求。
- `satisfies readonly Code[]` 只檢查子集合，新增 failure code 會讓 `authoringErrorStatuses` 回 undefined、transport 把 422 悄悄降級成 500；改以 `Exclude<..., typeof list[number]> extends never` 把漏列提前成編譯錯誤。
