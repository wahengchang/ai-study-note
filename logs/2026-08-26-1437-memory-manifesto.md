# MEMORY 宣言與工程邊界

## 交付

- 將 `MEMORY.md` 定義為精簡、可長期指導開發決策的專案宣言：真理、原則、規則與決策檢驗。
- 保留使用者確認、且目前對開發有拘束力的三項內容／投影、Route／Media／Artifact、Plugin host 工程邊界；它們獨立於宣言本體呈現。

## 關鍵決策

- 宣言只保留跨工具與實作世代仍成立的方向；不寫入日期、角色編制、分支位置、Q gate、生成指令或工作過程。
- 技術中立與已確認邊界並存：宣言不預設持久化技術；精確且已核准的工程約束置於「工程邊界」，隨架構決策更新。
