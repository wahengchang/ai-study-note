# Public delivery 與 CMS 工作摘要

**期間：** 2026-09-04 至 2026-09-09
**範圍：** ThemeHost、Projection/Preview、Renderer/Delivery、Public UI、CMS bootstrap/workspace 與 SEO/Plugin integration。

## 已交付

- 建立 verified Theme／Plugin evidence 驅動的 published-only Projection、sandboxed Preview、deterministic Renderer 與 immutable Delivery。
- 建立 Public UI 的 verified static artifact serving，以及 CMS browser ticket/session bootstrap。
- 交付 CMS entry、taxonomy、media、route、release 與 plugin editor surfaces；每個 surface 維持 exact API DTO、safe error、keyboard/focus/landmark browser gate。
- 建立 SEO Plugin settings、analysis 與 public contribution 的受控 callback boundary。

## 持久決策

- Public output 只讀 published projection；authoring database、current draft、Plugin/Theme 原始檔與內部錯誤不進 public artifact。
- CMS 僅透過 Authoring API Application façade 存取 owner；不得跨入 Persistence、Media、PluginHost 或 filesystem。
- 詳細決策見 [ADR](../docs/adr/README.md)，公開/運維 contract 見 [implementation contract](../contracts/README.md)。

## 驗證基準

各交付由 strict projection/renderer/delivery tests、Authoring API actual-listener tests、CMS production build 與 Chromium browser/a11y journeys 覆蓋。
