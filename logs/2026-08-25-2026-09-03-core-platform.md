# Core platform 工作摘要

**期間：** 2026-08-25 至 2026-09-03
**範圍：** local SQL canonical state、Persistence、DomainApplication、SiteDefinition、DataMedia、PluginHost 與初期 Authoring API。

## 已交付

- 確立 local SQL 為 authoring canonical state；Revision／schema history／pointer／lineage 維持 immutable 與 transaction-bound。
- 建立 SaveRevision、PublishRevision、RestoreRevision、ChangeRoute 的 Application command boundary，以及 current/published route graph isolation。
- 建立 verified local media import、reference、published selection、archive/restore 與 startup reconciliation。
- 建立 trusted Plugin discovery、explicit activation、durable identity evidence、validator/editor callback snapshot 與 safe diagnostic。
- 建立 localhost Authoring API 的 credential、admission、save/publish transport 基礎。

## 持久決策

- owner、public entry 與可觀察 contract 以 [implementation contract](../contracts/README.md) 為唯一準則。
- immutable source、explicit proposal/CAS evidence、single transaction 與 rejected command zero mutation 是共同不變量。
- 詳細架構決策見 [ADR](../docs/adr/README.md)；逐次變更與測試輸出保留在 Git history 與對應 PR。

## 驗證基準

各交付以 Persistence、Application、SiteDefinition、Media、PluginHost 的 contract tests 與 `npm run check:architecture` 驗證；現行可執行行為以程式與測試為 SSOT。
