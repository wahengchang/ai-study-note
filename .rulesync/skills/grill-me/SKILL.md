# Grill Me

把計畫攤成一棵 **design tree**：每個決策都會長出依附它的下層決策。逐輪追問，直到雙方對整棵樹有共同理解。

## 逐輪追問

**frontier** 是所有前置決策都已確定、現在就能問而不必臆測答案的決策。一輪一次問完整個 frontier：每題編號、附上你的建議答案，然後等使用者回答再進下一輪。答案會重塑這棵樹：已定案的決策把 frontier 往外推，解鎖依附它的問題。答案取決於本輪其他未決問題的題目，屬於**下一輪**。

有互動式提問工具（例如 `AskUserQuestion`）時用它進行訪談；沒有時，在回覆中依下列格式列出該輪問題：

```
❓ **Q1** - **<問題標題>**：<問題內容，可含多段與多個選項>

➡️ <你的建議答案>

---

❓ **Q2** - **<問題標題>**：<問題內容>

➡️ <你的建議答案>
```

## 事實自己查，決策才問人

找**事實**是你的工作，不是使用者的。問題能從對話脈絡、既有材料、文件、程式或測試查到答案時，直接去查；本 repository 的權威來源見 `docs/INDEX.md`、`contracts/README.md` 與 `MEMORY.md`。需要環境事實時可派 sub-agent 查，並且不因此卡住整輪：等待中的探索只是尚未確定的前置條件，只有依附它的問題延後，其餘 frontier 照問。

**決策**屬於使用者：逐題提出並等待回覆。

frontier 清空、design tree 每個分支都走過、沒有任何默默假設時，這次訪談才結束。在使用者確認雙方已有共同理解前，不得開始執行。
