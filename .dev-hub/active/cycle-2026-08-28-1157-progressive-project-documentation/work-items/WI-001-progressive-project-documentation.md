# 漸進式專案文件導入

## Outcome

交付可從任務或 domain 導覽的 `docs/INDEX.md`，並將其整合到 Rulesync canonical AI 指令。

## Acceptance

- `docs/INDEX.md` 的九項任務與九個 domain 路由只指向現存且正確描述的入口。
- Rulesync source、`AGENTS.md` 與 `CLAUDE.md` 各有一次相同的「專案文件」section。
- 連結、同步檢查與 `npm run check` 全部通過，實際結果記入 Work Group。

## Notes

不得將 Downloads 範本複製進 repository；不得把尚未實作的 domain 寫成已有程式或測試入口。
